# VoicePanel

Локальная панель диктовки для Windows и отдельный HTTP-сервис распознавания, коррекции, перевода и синтеза речи.

## Диктовка

Поставьте курсор в текстовое поле и нажмите **Ctrl+Alt+D**. Готовые предложения вставляются после распознавания и включённой обработки. Паузы завершают фрагменты, но не останавливают микрофон. Повторное нажатие завершает запись и ждёт оставшиеся задачи без повторной вставки.

**Ctrl+Alt+R** включает режим проверки. Второе нажатие завершает запись и обработку, затем открывает Preview. Вставка происходит только после нажатия Insert. Панель не нажимает Enter и не отправляет сообщение.

В Preview слева находится исходный текст, справа — редактируемый результат. Исправления можно принять или отклонить. Ручные правки сохраняются при поступлении поздних ответов. **Ctrl+Alt+S** сохраняет проверенный текст в выбранную папку Markdown.

## Возможности

- Непрерывная запись с Silero VAD и упорядоченными финальными результатами.
- Локальная коррекция и перевод между русским и английским.
- Вставка в запомненное поле через Windows UI Automation или буфер обмена.
- Сохранение текста при ошибке вставки и безопасный повтор.
- Озвучка текста, экспорт WAV и локальные голосовые профили.
- Живые сессии: окно переводчика (звонок и микрофон рядом), встречи с вкладками Notes и Transcript и субтитры поверх любого приложения. Остановка встречи сохраняет один Markdown-файл.
- Независимый сервер, API и значок сервера в трее.

## Установка

Репозиторий содержит исходники. Модели, движки, Qt и ONNX Runtime загружаются отдельно. Готового автономного установщика здесь нет.

Следуйте [инструкции по подготовке и запуску](../getting-started.md). Проверенный загрузчик фиксирует версии и SHA-256 в `tools/downloads.lock.json`, проверяет файлы перед распаковкой и не запускает загруженные программы. Для запуска панели нужны Windows 11 x64, Python 3.12 x64, Visual Studio 2022 с C++, CMake/Ninja и Qt 6.8.3 для MSVC 2022.

Рабочая конфигурация — `config.yaml`, публичный пример — `config.example.yaml`. Основной сервис распознавания и обработка текста используют CPU. Клонирование голоса выполняет отдельный движок omnivoice.cpp (OmniVoice Q8, ~945 МБ, 600+ языков; веса CC-BY-NC — скачиваются отдельно), а переключатель CPU/GPU в панели переводит распознавание, клонирование и обработку текста на CUDA — это режим реального времени для созвонов и живого переводчика. Крупная альтернатива `qwen3-tts-clone` (2 ГБ, ru/en) остаётся в примере конфигурации как документированный вариант. Русские базовые голоса — Piper: мужской `piper-ru` (Ruslan) и женский `piper-ru-female` (Irina). Проверенные модели с измеренными показателями — в [Models](../models.md).

Выбор движков сохраняется до следующего запуска сервиса. В трее откройте **Server settings → Choose backends**. Для TTS доступны OmniVoice и audio.cpp. Для распознавания доступны audio.cpp и Whisper. Qwen3-TTS остается альтернативой через audio.cpp. CPU/GPU переключает процесс выбранной модели. Выбор не загружает новые веса.

В Settings и Voice playback параметры дизайна голоса появляются для моделей с этой поддержкой. Для Piper и Kokoro они скрыты. Сохраненный клон содержит эталон голоса. Для озвучки по этому эталону нужна TTS-модель. Нативный HTTP-сервер OmniVoice держит один экземпляр модели при смене голосов и языков.

Показатели видеопамяти OmniVoice сняты после запросов. Это не пиковые значения. У новой a650381 расход RAM после GPU-запросов примерно на 120 МиБ выше прежнего. Сравнение ее видеопамяти не дало надежного результата из-за переменной фоновой нагрузки. Упакованный GGUF не заменяет малую пару в базовой конфигурации. Обновление использует llama.cpp 1.0 / b12359. Условия, источники, сравнение CPU, потоковый NeMo и ограничения проверок описаны в [отчете](../runtime-update-2026-11-17.md).

## Безопасность и данные

Оставьте сервис на `127.0.0.1`. HTTP и WebSocket используют общие проверки Host, Origin и токена. Не публикуйте записи, голосовые эталоны, контекст, API-ключи, журналы и локальные настройки. Папка `runtime/` исключена из Git. При выборе внешней LLM текст и контекст передаются выбранному серверу.

Подробности: [безопасность](../../SECURITY.md), [API](../api.md), [CPU и GPU](../compute-profiles.md), [проверки](../testing.md).

## Будущие голосовые сообщения

Прямая передача аудио и голосовые сообщения отложены. Текущая версия не отправляет их. Возможное развитие отдельно описано в [планах](../../ROADMAP.md).
