# VoicePanel 0.3.2

This release folds an empty subtitle phrase into the next caption instead of
giving it a line of its own. It is the merge variant the 0.3.1 notes named as
the next attempt; 0.3.1's caption timing, speaker identity, single-voice
acceptance, `diagnose` and prompt fix are included.

## Getting the models

The archive ships no weights: they are large, licensed separately and chosen per
slot in `config.yaml`, so one CPU-only archive serves every setup. It does ship
the verified downloader. In the unpacked `VoicePanel` folder, with Python 3.12:

```powershell
python tools\download_runtime.py --list
python tools\download_runtime.py --group runtime     # recogniser, built-in voices, LLM, Whisper
python tools\download_runtime.py --group extras      # ONNX Runtime SDK and Silero VAD
python tools\download_runtime.py --group clone       # optional audio.cpp clone model
```

Every file is checked against the SHA-256 in `tools/downloads.lock.json` before
it is extracted, and nothing downloaded is executed. Sources, sizes, tested
variants and per-slot swapping live in [Models](../models.md) and [Getting
started](../getting-started.md); the default cloning engine (omnivoice.cpp plus
the OmniVoice Q8 weights from HF `Serveurperso/OmniVoice-GGUF`) is not in the
lock and is described there.

## The fragment joins its neighbour

A remote phrase the recogniser returns no words for is a boundary fragment: the
tail of a word whose beginning is already in the previous caption, or the start
of the next reply. It is not a sentence of its own and no amount of retrying
finds words in it.

Its audio is now held, and the next phrase is recognised with the fragment
prepended, bounded to 3 s. The fragment never becomes a caption line; its words
reach the reader inside the next caption, and the caption's span and label cover
the merged audio. No extra request is made — the merge replaces a request that
would have returned nothing. A fragment at the very end of a session has no next
phrase: it is held, never captioned, and dropped on stop.

Two empties in a row do not queue two fragments: the first goes into the second
phrase's request, and if that also comes back empty the combined audio is held
as one unit for the phrase after it.

## Measured

Two runs on the 600-second, three-voice fixture (137 phrases, 97 reference
turns), against the 0.3.1 baseline:

| Measure | 0.3.1 | 0.3.2 |
|---|---|---|
| WER / CER | 0.303 / 0.224 | **0.285 / 0.217** |
| Lost turns | 20.6 % (20/97) | **14.4 % (14/97)** |
| Empty phrases (by segment) | 14.6 % (20/137) | 14.6 % (20/137) |
| Empty lines on the card | 20 | **0** |
| Speaker names | 92.3 % | 94.0–95.7 % |
| Term recall | 79.5 % | 82.1 % |
| Caption order | 0 / 0 | 0 / 0 |
| Median steady → last third | 187 → 186 ms | 186 → 186 / 187 ms |

The per-segment empty share does not move because the fragment still contains no
words of its own. What moves is what the reader sees: every one of the 20
fragments is folded into the next caption, so the card has no empty line, and
the words the fragment carried now reach the transcript through that caption.
Lost turns and WER improve on the same fixture, with no extra requests and no
latency change.

## Model-free coverage

`emptyPhrasesFoldIntoTheNextCaptionAndTrailingFragmentIsDropped` drives the
controller through a local test server: two empty phrases in a row, then a
phrase with words, then a fragment at the end of the session. It checks that the
third request carries all three phrases' audio (24 000 samples at 16 kHz), that
the two fragments are counted as folded, that the trailing fragment is held but
never captioned, and that `stop()` clears it. No model is needed.

## Known limitations

- The empty-phrase share counted by segment stays at 14.6 %; the release removes the visible gap, not the fact that the fragment has no words.
- A fragment at the end of a session is dropped, not captioned.
- A caption still appears after the VAD endpoint rather than while audio arrives.
- Speaker labels are not renameable in the subtitles overlay.
- Quality figures come from an English fixture; Russian meetings are not measured.
